# structured-innovation-ai-agents-poster
Structured Innovation coursework poster on AI agents and OpenClaw.

This repository contains the final poster PDF and supporting materials for the Structured Innovation coursework.

The poster discusses AI agents through the case of OpenClaw. The written content is based on official OpenClaw documentation, IBM’s explanation of AI agents, OpenAI documentation on tokens and reasoning models, and an academic survey on LLM-based autonomous agents.

The central lobster illustration is original artwork created by the group. No external lobster image was used.
